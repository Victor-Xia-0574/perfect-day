# 完美的一天打卡（PWA 版）

每天五项，每项至少 5 分钟，做了就是完美的一天。
纯静态网页：不用服务器、不用账号、不用命令行，数据只存在你自己的手机浏览器里。

## 挂到 GitHub Pages（不用命令行，全程网页点一点）

1. 打开 github.com，注册/登录一个免费账号。
2. 右上角 `+` → New repository，新建一个仓库：
   - 名字随便起，比如 `perfect-day`；
   - 一定选 **Public**（公开，免费账号只有公开仓库能开 Pages）；
   - 点 Create repository。
3. 在仓库页面点 **Add file → Upload files**，把本文件夹里的**全部文件**（index.html、style.css、app.js、sw.js、manifest.webmanifest、icon-180.png、icon-192.png、icon-512.png）一起拖进去，点 Commit changes。
   - 注意：文件要放在仓库根目录，不要包在子文件夹里。
4. 点仓库的 **Settings → Pages**：
   - Build and deployment → Source 选 **Deploy from a branch**；
   - Branch 选 **main**，文件夹选 **/ (root)**，点 Save。
5. 等 1–2 分钟，刷新这个页面，顶部会出现你的地址：
   `https://你的用户名.github.io/perfect-day/`
6. iPhone 上用 Safari 打开这个地址（先关掉 VPN 试一下能不能直连）：
   - 点底部中间的分享按钮（方框带向上箭头）→ **添加到主屏幕** → 添加。
   - 以后点主屏幕图标就能全屏打开，跟 App 一样，不用经过 Muse、不用挂 VPN。
   - 第一次打开要联网加载，之后离线也能打开打卡。

## 功能

- 每天一张卡：开发、维护、英语、锻炼、副业五项。
- 每项点「开始专注」跑倒计时，跑满自动打勾（没有手动“完成”按钮，这是定好的规矩）。
- 来不及计时就点「直接打卡」，一键算数。
- 顶部进度条：今天 · x/5，带百分比，五项全满变金色，出现“今天完整了”。
- 连续天数、累计完美、最长连续、本月完美四个数。
- 过去 12 周格子：金色是完美的一天，点任意一天能看当天做了什么，也能补打卡。
- 断了不罚：链子断了只显示一句“今天做满就是新链子的第一天”。
- 每项能记一笔（副业想到的点子就记在那儿）。
- 「管理项目」里能改名、改目标分钟数、调顺序、增删。

## 两句提醒

- 数据只存在这台手机的浏览器里：换手机、清浏览器数据，记录就没了。重要的天数可以时不时截图留底。
- 如果 GitHub Pages 在你手机上不关 VPN 打不开，就换一家再试：同样的文件上传到 Cloudflare Pages 或 Vercel 也能用，步骤大同小异。
- 以后改版：把新文件重新上传覆盖一遍，手机上刷新一次就更新了（改 sw.js 里 CACHE_NAME 的版本号能确保旧缓存被清掉）。
